# CrypticCare - Telemedicine Security System

A dual-layered telemedicine data protection system using **LSB & DCT Steganography** combined with **AES-128 Encryption**.

## Features
- **AES Cryptography**: Encrypts sensitive patient records before embedding.
- **LSB & DCT Steganography**: Conceals encrypted text imperceptibly inside medical cover images.
- **Web Portal**: Easy-to-use Flask web interface for healthcare providers and doctors.
- **Data Integrity & Confidentiality**: Ensures medical data remains tamper-proof during transmission.

## ️Tech Stack
- **Backend / Web**: Python, Flask
- **Security / Algorithms**: AES Encryption (PyCryptodome), LSB & DCT Pixel Manipulation
- **Image Processing**: OpenCV, Pillow (PIL)
- **Frontend**: HTML5, CSS3, Bootstrap 5
